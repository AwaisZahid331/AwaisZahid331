### Hey, I'm Awais 👋

I'm a Full Stack AI Developer based in Lahore, Pakistan. I build things where LLMs actually do useful work. Not just chatbots, but agents that reason, take action, and recover when something breaks. I've spent the last 3 years shipping production systems across fintech, retail, education, and automation. Right now I'm a Software Engineer at CBSOL, where I design and deploy multi-agent workflows, RAG pipelines, and AI-integrated full stack apps on AWS. I also led development as Team Lead on PXEngine, a multi-agent platform live at `app.pxengine.ai`. 

My stack lives at the intersection of Python + FastAPI + LangChain on the AI side and React + Next.js + Node.js on the product side. I care about systems that actually work in production, not just in demos.

* 🤖 Building autonomous AI agents and multi-agent orchestration systems
* 🚀 Shipping production AI on AWS + Docker
* 🛠️ Working daily with Claude Code, Cursor and MCP servers
* 💼 Open to full-time roles, remote freelance work and collaborations
* 📍 Lahore, Pakistan
